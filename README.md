# 研究室 レイアウト検討

| ページ | 内容 |
|---|---|
| [index.html](./) | 原案（Ver 9.1）の3Dウォークスルー（A-Frame） |
| [viewer.html](./viewer.html) | 統合3案ビューア（three.js・編集機能つき） |

## viewer.html でできること

- **4案の切替** — 案A / 案B / 案C / 案F（原案）
- **仕切り高さスライダー** H900〜1800（着座1,200・立位1,600の視線判定つき）
- **収納量の比較** 4案の実効容積をグラフ表示
- **視点** 俯瞰 / ウォークスルー（WASD）/ 平面図
- **編集モード** ドラッグで移動、平面図モードでは黄色いハンドルから大きさを自由に変更
- **自動チェック** 室外はみ出し・什器の重なり・扉の開閉範囲・機器の離隔を随時判定
- 日照シミュレーション、天井/壁透過の切替、PNG書き出し、JSON入出力

three.js は同梱しているため、オフラインでも動作します。

室寸法: 内法 7,245 × 7,630 mm / 天井高 2,700 mm
